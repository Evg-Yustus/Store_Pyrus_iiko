# Store_Pyrus_iiko

Статический каталог плагинов Pyrus iiko Helper для GitHub Pages.

## Файлы

- `catalog.json` — каталог, собранный из JSON-манифестов ветки `plagin`.
- `index.html` — страница каталога с поиском и фильтром по категориям.

Сейчас записи помечены как встроенные в расширение. Отдельная установка из магазина ещё не подключена.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и каталог `/ (root)`.

После публикации страница будет доступна по адресу:

https://evg-yustus.github.io/Store_Pyrus_iiko/
